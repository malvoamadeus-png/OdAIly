# OdAIly 官方后台快讯补充数据拉取接口

本文供 Odaily 官方后台技术人员接入 OdAIly 已发布快讯的补充审核数据。官方快讯 ID 是唯一关联键；标题、正文、官方操作人和浏览量继续以官方后台数据为准。

## 接口

生产地址：`https://api.odaily.uk/integration/newsflashes`

```http
GET /integration/newsflashes?limit=100&offset=0 HTTP/1.1
Host: api.odaily.uk
Authorization: Bearer <NEWSFLASH_EXPORT_API_TOKEN>
Accept: application/json
```

请求必须使用 HTTPS。接口只允许 GET，不接受官方后台写入。OdAIly 的生产环境配置 `NEWSFLASH_EXPORT_API_TOKEN`；官方后台将同一密钥存入自己的密钥管理系统，通过 `Authorization` 请求头传入。密钥通过单独的安全渠道交付，不提交到代码仓库或普通配置文件。

## 查询参数

| 参数 | 类型 | 默认值 | 说明 |
|---|---|---:|---|
| `limit` | integer | 100 | 每页条数，最小 1、最大 500；大于 500 时按 500 返回 |
| `offset` | integer | 0 | 从结果集起始位置计算的偏移量，必须大于或等于 0 |

结果按发布时间从新到旧排列。同一官方快讯 ID 应使用 upsert 方式写入接收端。当前接口提供 offset 分页，不提供 `updated_since` 或游标；接收端应定期重新拉取并按 ID 幂等更新。

## 字段

| 字段 | 类型 | 含义 |
|---|---|---|
| `id` | string | Odaily 官方快讯 ID，唯一关联键 |
| `published_at` | string/null | 官方快讯发布时间 |
| `outlet_category` | string | 独立出口品类：`人工`、`AI常规`、`商务`、`行情`、`Meme速递`、`热点自动快讯`、`定时简报` |
| `priority_level` | `high`/`medium`/`low`/null | 审阅优先级；只传等级，不传理由；无适用等级时为 null |
| `text_review.status` | string | 文本审查当前状态：`unreviewed`、`pending`、`processing`、`passed`、`flagged`、`failed` 或 `skipped` |
| `text_review.feedback` | object/null | 与当前官方标题和正文版本匹配的完整文本审查反馈结构 |
| `text_review.text` | string | 插件侧展示的审查文本 |
| `text_review.updated_at` | string/null | 文本审查更新时间 |
| `fact_review.status` | string | 事实审查当前状态：`unreviewed`、`pending`、`processing`、`skipped`、`exempt`、`passed`、`flagged`、`unverifiable` 或 `failed` |
| `fact_review.text` | string | 插件侧事实审查短文本；没有疑点时为空字符串 |
| `fact_review.url` | string | OdAIly 快讯详情中对应事实审查的链接 |
| `fact_review.updated_at` | string/null | 事实审查更新时间 |
| `duplicate.status` | string | 当前固定为 `not_implemented`，仅预留字段 |
| `duplicate.text`、`duplicate.url` | string/null | 当前为 null，暂不提供查重结论 |
| `read_status.is_read` | boolean | 当前标题/正文版本是否至少有一名编辑完成有效阅读 |
| `read_status.readers` | array | 当前版本阅读留痕；含操作者、首次/最近阅读时间、次数和方式 |
| `updated_at` | string/null | 该条导出数据所关联记录的最近更新时间 |
| `total` | integer | 满足导出条件的快讯总数 |
| `next_offset` | integer/null | 下一页偏移量；无下一页时为 null |

阅读方式 `read_method` 当前为 `alt_lens`（Alt 阅读层成功显示正文）或 `title_expand`（插件点击标题成功展开正文）。只查看列表标题不计为已读。阅读记录绑定标题与正文版本；内容版本变化后，旧版本阅读记录不计入当前 `read_status`。

响应不包含 `title` 或 `content`。官方后台使用自己的标题、正文与其他原生字段；OdAIly 仅提供上表中的补充数据。只有已精确关联官方快讯 ID 的记录才会导出。

## 拉取示例

```bash
curl --fail-with-body \
  -H "Authorization: Bearer ${NEWSFLASH_EXPORT_API_TOKEN}" \
  -H "Accept: application/json" \
  "https://api.odaily.uk/integration/newsflashes?limit=100&offset=0"
```

接收端按 `data.items[*].id` 幂等更新本地补充字段；当 `next_offset` 不为 null 时，使用其值请求下一页。

## 错误响应

| HTTP 状态 | 含义 |
|---:|---|
| `400` | `limit` 或 `offset` 格式/范围无效 |
| `401` | Bearer 密钥缺失或不匹配 |
| `503` | OdAIly 尚未配置 `NEWSFLASH_EXPORT_API_TOKEN` |
| `500` | 导出查询失败；响应不会泄露内部异常细节 |

错误响应格式为 `{"ok":false,"message":"..."}`。响应带 `Cache-Control: no-store`，接收端不应缓存鉴权结果或响应内容。

## 当前边界

- 官方后台操作人、浏览量和阅读动作回传 OdAIly 的接口尚未实现。
- 官方后台文本审查接受/拒绝和事实审查跳转留痕的同步尚未实现。
- 查重暂未接入，字段只作占位。
- 官方后台应以自己的稿件数据为准，不使用此接口覆盖标题、正文、官方操作人或浏览量。
