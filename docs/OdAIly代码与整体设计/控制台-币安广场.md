# 控制台-币安广场

## 职责

`信源管理 > 币安广场` 管理实验性币安广场账号监控。页面只写主 SQLite 配置，不直接启动浏览器或 systemd 服务。

## 页面能力

- 显示实验性风险、固定 180 秒频率、总开关、worker 状态和最近心跳。
- 只接受币安官方 `/square/profile/{slug}` 主页链接；拒绝帖子链接和非币安域名。
- 支持新增、暂停、启用、删除账号，以及编辑显示名和写作名。
- 展示每个账号的基线状态、最近轮询、最近成功和错误。
- 展示最近 30 次采集尝试。

总开关默认为关闭。打开后页面必须提示仍需运维启动 `odaily-binance-square.service`；关闭后，已经运行的 worker 会在下一次配置读取时停止采集。

## 存储接口

页面通过认证后的 `/console/data` 读写：

- `binance_square_settings`
- `binance_square_accounts`
- `binance_square_attempts`（只由 worker 写入，页面仅展示）

`binance_square_seen_posts` 不暴露给控制台，避免人工改写去重账本。
