# 判断者-领域分类

## 职责

这是 `external_media_alert` 的 `domain_judge` 阶段。

它负责判断 Crypto信源标题提醒和 AI信源标题提醒是否属于 Crypto，并决定是否继续进入查重与提醒。

## 当前生产输入

- `tasks.source = 'external_media_alert'`
- `tasks.source = 'ai_source_alert'`

主要来自统一 Crypto信源收集器中的 `alert_only` 站点：

- FT Crypto
- WSJ Business / Economy / Finance
- Fortune Crypto
- The Block
- Bloomberg RSS（使用独立判断 Prompt）

AI信源标题提醒当前没有生产站点，但链路已保留 `ai_source_alert` 输入合同；提示词中的任务类型会显示为“AI信源标题提醒”。

## 历史兼容输入

- `tasks.source = 'mainstream_media'`

这类任务只为历史数据保留兼容，不再由新的收集入口生成。

## 输出

- 保留：`route = 'crypto'`
- 丢弃：`route = 'discard'`

如果模型输出了 `{"route":"discard"}` 但漏掉 `discard_reason`，worker 会兼容按 `non_crypto` 处理，避免任务卡在 `domain_failed`。

## Prompt

- `template_key = 'external_media_alert_domain_judge'`
- 需要同时兼容标题提醒和历史 `mainstream_media` 快讯任务
- 模型由 `EXTERNAL_MEDIA_ALERT_DOMAIN_JUDGE_MODEL` 配置，默认 `gpt-6-luna`
- 判断请求固定使用 `reasoning_effort=none`，即不思考模式
- 该设置同时用于 Bloomberg 专属判断和其他标题提醒领域判断

## Bloomberg 独立判断

- 输入任务的 `metadata.site_key = 'bloomberg_news'` 时，使用 `template_key = 'bloomberg_alert_domain_judge'`，不调用通用 Crypto / 非 Crypto 判断 Prompt
- 只依据标题和 RSS 摘要判断核心事件；Crypto、特朗普、AI 可多选。命中至少一个类别即准入，否则以 `outside_watchlist` 丢弃
- `domain_route = 'bloomberg'` 表示通过 Bloomberg 专属判断；标准化类别保存在 `domain_output.categories`，提醒卡显示对应主题
- Bloomberg 规则和范围见 `Bloomberg标题主题判断模板.txt`
