# 美国宏观数据快讯

## 范围

`macro-newsflash` 是独立常驻 worker，不创建 `tasks`，不进入判断者、搜索者、编写者1或发布者状态机。每项指标按统计期单独生成一条标题和正文，不包含市场预测值，也不比较“高于/低于预期”。

标题统一为“美国XX月XX指标录得XX，前值XX”；正文使用“据Odaily监测，美国……”句式，再由编写者2的 `format_brief` 做最终格式整理。格式器会在正文前补 `Odaily星球日报讯 `。Push Data API 必须显式收到 `isPublish=false`、`isPush=false`。

## 指标与口径

| 指标 | 来源与计算 |
| --- | --- |
| 零售销售月率 | FRED `RSAFS`，季调后的零售与餐饮服务名义销售额；按相邻月金额计算环比。该序列来源机构为 Census。 |
| 当周初请失业金人数 | FRED `ICSA`，季调初请人数；单位转换为万人，前值为上一周观察值。来源机构为 DOL ETA。 |
| 利率决议 | Federal Reserve monetary press release feed 和声明页面；解析联邦基金利率目标区间，并与上一份 FOMC 声明区间比较，标题说明维持、上调或下调。 |
| PCE 物价指数年率 | FRED `PCEPI`，Headline PCE 月度季调价格指数；按当月和12个月前指数计算同比。来源机构为 BEA。 |
| 季调后非农就业人口 | 首选 BLS API `CES0000000001`；接口失败时回退 FRED 镜像 `PAYEMS`。相邻月季调就业水平差值由千人转为万人。前值按同一当前数据版本计算上一月变化。 |
| 月失业率 | 首选 BLS API `LNS14000000`；失败时回退 FRED 镜像 `UNRATE`，均为全国季调失业率。 |
| CPI 未季调年率 / 月率 | 首选 BLS API `CUUR0000SA0`；失败时回退 FRED 镜像 `CPIAUCNS`。CPI-U 全项目未季调指数分别按12个月和1个月指数差计算。 |
| CPI 季调月率 | 首选 BLS API `CUSR0000SA0`；失败时回退 FRED 镜像 `CPIAUCSL`，使用 CPI-U 全项目季调指数。 |
| 核心 CPI 季调月率 | 首选 BLS API `CUSR0000SA0L1E`；失败时回退 FRED 镜像 `CPILFESL`，使用剔除食品和能源的 CPI-U 季调指数。 |

同一 CPI 发布期会为上述四个 CPI 字段分别生成快讯。未季调月率不与常见的季调月率混称。金额和指数计算后保留一位小数；非农与初请按万人显示。每条稿件的前值来自当前来源快照中的上一统计期，支持来源已修订的最新值；SQLite 同时保存本条稿件使用过的原始响应，不会回写旧稿。

## 发现发布时间

worker 每6小时同步 BLS、Census、BEA 和美联储官方发布日历，并查询 TradingView 结构化经济日历补充 Census 零售月率与 DOL 初请的已公布排程。TradingView 事件只有在国家、指标标题和来源机构均匹配时才接纳；它只用于发布日期，不提供快讯实际值。第三方排程会标注 `TradingView` 来源，和官方日历来源区分。若没有第三方初请发布日期，才按 DOL 通常周四 08:30 规律生成估算；周四与主要美国假日重合时按周三估算，并标明 `is_estimate=true`。同一指标同一日期去重，已公布排程优先于规律估算，直接 Census 日历优先于 TradingView 补充项。

临近日历事件前2小时至后3小时，worker 每30秒只读取与该事件对应的数据源；多个事件同一时间发布时会合并请求。没有临近事件时不拉取指标序列，只在日历到期时刷新排程。它不以固定的北京时间作为触发条件，因此夏令时切换、日历公布的节假日顺延和机构临时改期不需要修改 cron；最终仍以来源出现新统计期作为发布触发条件。官方及补充日历无法访问或结构无法识别时，worker 保留上次成功的日历，15分钟后重试，并回退到美东工作日 08:20–10:30 检查 BLS/Census/BEA 数据、13:50–15:30 检查 Fed 声明。常规发布窗口内，从来源更新到下一次轮询最多增加一个30秒轮询周期，FRED 托管的序列还会叠加 FRED 自身的同步延迟。

零售销售、初请和 PCE 暂用 FRED 的 Census、DOL ETA、BEA 来源序列；指标实际值更新节奏受 FRED 同步时间影响。TradingView 日历只补充日期和时间，且来源字段必须分别匹配 Census Bureau 或 Department of Labour。BLS 指标首选 BLS API，接口错误或缺少序列时整体回退到对应的 FRED 镜像；结果的来源名称和链接会标明 FRED 镜像。FRED 的同步时间可能晚于 BLS 首发，因此回退可用性不代表首发速度与 BLS API 相同。FRED CSV 请求使用生产环境验证可访问的 User-Agent。FOMC 直接读取美联储的声明 feed 和声明正文。

所有来源逐项独立处理；单个来源失败不会阻止其他指标。未取得连续统计期、单位异常、声明目标区间解析失败或数据源返回空值时，该指标本轮不生成快讯，并在 worker 日志中记录来源错误。排程日历决定何时加快检查，指标实际新统计期决定是否创建快讯；因此日历时间不准确不会直接生成错误数值。

## 去重与投递

- `data/runtime/macro_newsflash.sqlite` 是独立 SQLite，不属于主任务库。
- `macro_metric_state` 保存每项指标最后观察的统计期、来源和原始快照。
- `macro_release_schedule` 保存 BLS、Census、BEA、美联储、TradingView 补充排程及初请规律估算；status 命令同时显示日历更新时间和解析失败来源。
- `macro_newsflash_events` 以 `指标 ID + 统计期` 唯一键保存标题、正文、当前值、前值、原始响应和投递状态。
- 首次启动默认只建立当前统计期基线，不补发历史数据。人工核对后可单次运行 `--publish-latest` 发布当前可见统计期。
- 状态 `pending` 表示等待投递，`publishing` 表示 API 调用已开始，`published` 表示成功，`uncertain` 表示调用失败或进程中断、结果无法确认。`uncertain` 不会自动重试，需先检查后台和信息流，避免产生重复稿。
- 每个事件只调用 Push Data API 一次，并传 `Idempotency-Key`；本地去重是主要保障，服务端是否执行幂等仍取决于接收接口实现。

## 控制台只读页

控制台“行情播报 / 美国数据追踪”通过认证的 `GET /console/macro-newsflash/get` 只读本库，展示未来排程及北京时间/美东时间、已公布排程或规律估算标记、日历解析错误、最近数据源检查错误、最近观测统计期及对应当前值/前值和快讯投递状态。指标快照同时保存格式化的当前值和前值，因此首次只建立基线时也可展示数值。页面不初始化数据库，不触发来源请求，也不推进投递状态；数据库缺失或尚未初始化时明确显示 worker 尚未初始化。前端仅在进入页面或手动刷新时读取快照。

## 操作

```bash
python backend/src/main.py macro-newsflash init-db
python backend/src/main.py macro-newsflash run --once
python backend/src/main.py macro-newsflash run
python backend/src/main.py macro-newsflash status
```

`run --once` 会读取数据源并执行真实的挂后台投递；首次运行默认建立基线。单次发布当前最新数据前，先核实数值再使用：

```bash
python backend/src/main.py macro-newsflash run --once --publish-latest
```

`MACRO_NEWSFLASH_POLL_INTERVAL_SECONDS` 默认 `30`，最小为 `10`；`MACRO_NEWSFLASH_QUIET_POLL_INTERVAL_SECONDS` 默认 `900`，最小为 `60`。`MACRO_NEWSFLASH_DB_PATH` 可覆盖独立 SQLite 路径；`MACRO_NEWSFLASH_REQUEST_TIMEOUT_SECONDS`、`MACRO_NEWSFLASH_PUSH_TIMEOUT_SECONDS` 调整超时；推送地址复用 `ODAILY_PUSH_ENDPOINT`。BLS API Key 可选，通过 `BLS_API_KEY` 配置；`MACRO_NEWSFLASH_TRADINGVIEW_CALENDAR_URL` 可覆盖第三方日历地址。生产 unit 为 `deploy/odaily-macro-newsflash.service`；部署仍按仓库规定先在本地提交并推送，再由官方服务器同步。

官方日历与数据入口：[BLS 新闻发布日历](https://www.bls.gov/schedule/news_release/)、[Census 经济指标日历](https://www.census.gov/economic-indicators/calendar-listview.html)、[BEA 发布日历](https://www.bea.gov/news/schedule)、[美联储 FOMC 日历](https://www.federalreserve.gov/monetarypolicy/fomccalendars.htm)、[美联储货币政策 RSS](https://www.federalreserve.gov/feeds/press_monetary.xml)、[DOL Weekly Claims Data](https://oui.doleta.gov/unemploy/claims.asp)。补充日历：[TradingView Economic Calendar](https://www.tradingview.com/economic-calendar/)（仅用于发布日期与时间）。
