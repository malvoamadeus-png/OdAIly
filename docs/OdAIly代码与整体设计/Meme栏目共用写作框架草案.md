# Meme栏目共用写作框架

更新日期：2026-10-26。适用于Meme速递与今日热门Meme。文件名保留原草案路径，内容为已确认的实现契约。

## 读者目标与类型

先阅读《中文写作风格规范》。正文回答市场以什么角度、理由和逻辑炒作该代币，不复述监控或聊天过程。

写作者在同一次结构化调用中先判断 `primary_type`，再按类型写正文并记录材料ID：

| 类型 | 正文入口 |
| --- | --- |
| `pure_meme` 纯Meme | 直接交代梗、名称、具体说法或事件来历，再解释炒作理由。 |
| `celebrity_anchor` 名人币 | 直接写人物或官方账号做了什么，再写市场解读。不能将社区转述编成原始人物动作。 |
| `app_linked` 应用币 | 直接定义项目做什么，再解释功能或机制与炒作理由。 |

“做什么”只适用于有实际产品的项目。近期动作仅在补充、增强或改变炒作逻辑时采用；没有相关进展就省略，不强制填段。正文不显示分类名或模板小标题。

## 来源与Grok

Telegram使用“群聊 A/B”匿名归属，不展示真实群名和普通用户名；FOMO Thesis使用“某信源表示”；官方原始动作可以直接写官方主体。

Grok Bot可用调研结果单独成段，固定以 `Grok补充资料显示，` 开头，总结炒作理由，允许重复前文。直接采用返回内容，不增加二次验证门槛或自动添加“尚未核实”等套话；保留返回材料中明确的计划、传言和推测性质。

Grok失败或15分钟未回传，使用其他可用材料继续写作，省略Grok段落。没有任何可用叙事就不挂后台。HTTP接单回执不等于调查完成。

## 文本外壳

Meme速递保留市值里程碑/社群热议标题、`据Odaily Meme速递监测，`导语和现行固定风险提示。

今日热门Meme使用 `今日热门Meme：{链}上{代币}市值突破{市值}万美元` 标题，采用入选行情快照；导语为 `据Odaily今日热门Meme监测，`。固定风险提示复用Meme速递文案，将栏目名换成“「今日热门Meme」”。标题中的“突破”按用户指定口径使用，不新增市值里程碑判断。

两个栏目独立触发、独立去重，共用材料、分类写作及挂后台能力。今日热门Meme直接介绍GMGN首次达标的热门币，不执行“新币蹭龙头要素”或购买价值判断。
