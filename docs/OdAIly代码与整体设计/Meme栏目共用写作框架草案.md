# Meme栏目共用写作框架

更新日期：2026-11-16。适用于Meme速递与今日热门Meme。文件名保留原草案路径，内容为已确认的实现契约。

## 读者目标与固定正文结构

正文的任务是让读者知道这枚代币关联什么，以及市场围绕什么逻辑炒作。固定写成一个自然段、两句话：

1. 第一句简要交代“是什么”：代币借用的梗、人物、事件、活动或项目。纯Meme可用一个短分句交代名称或起源；不展开无关背景。
2. 第二句必须以 `核心逻辑是` 开头，直接说明炒作逻辑，并把最相关的事实及来源归属融入这句话。

不要在第二句之后重复解释“代币借用了什么”“炒作点是什么”。没有材料支持核心逻辑时留空，不用起源、歌词感受、产品介绍或来源数量填充。

`primary_type`（`pure_meme`、`celebrity_anchor`、`app_linked`）只用于内部分类，不决定段落顺序，也不显示在正文中。第一句按实际材料说明对象；人物仅表示将采取行动时保留其意向状态，第三方转述不得写成人物已经行动。

## 材料与Grok

来源材料、炒作逻辑材料和补充信息按它们在正文中的作用分类，不按提供材料的工具分类。保留准确归属；将用户观点、人物表态、已发生动作、传言和推测分别写清。

Grok Bot继续承担跨平台调研。写作者综合 Grok 的 `what_it_is`、`primary_narrative`、`narratives`、`evidence` 和 `caveats` 与本地材料，选取最相关的内容写入固定两句正文；仅当这些结构化字段缺失时才使用旧版 `summary`。Grok不再固定占用独立段落；重复或与主逻辑无关的材料可以不写。若采用的结论有具体原始来源，优先归因到该来源；缺少原始来源信息时可归因于Grok调研。Grok可作为唯一可用材料来源，但不得把推测写成已发生事实。

Telegram使用“群聊 A/B”匿名归属，不展示真实群名和普通用户名；FOMO Thesis使用“某信源表示”，不得出现 FOMO、Thesis、产品名、作者名或账号名。官方原始动作可以直接写官方主体。

## 文本外壳

Meme速递保留市值里程碑/社群热议标题、`据Odaily Meme速递监测，`导语和现行固定风险提示。

今日热门Meme使用 `今日热门Meme：{链}上{代币}市值突破{市值}万美元` 标题，采用入选行情快照；导语为 `据Odaily今日热门Meme监测，`。固定风险提示复用Meme速递文案，将栏目名换成“「今日热门Meme」”。标题中的“突破”按用户指定口径使用，不新增市值里程碑判断。

两个栏目独立触发、独立去重，共用材料、叙事逻辑整理、固定结构写作及挂后台能力。今日热门Meme直接介绍GMGN首次达标的热门币，不执行“新币蹭龙头要素”或购买价值判断。
