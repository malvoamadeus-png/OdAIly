# 控制台-AI查重

## 定位

`AI查重` 是控制台一级标签，面向值班编辑提供一个可直接粘贴内容的查重入口。它复用 Chrome 插件已有的搜索者查重能力，方便编辑在不打开插件的情况下核对一段待发快讯。

## 页面交互

- 左侧输入框接收快讯标题或正文；空内容不能提交。
- 点击 `开始查重` 后显示请求中的状态，期间按钮不可重复提交。
- 结果区先显示搜索者结论：`疑似重复` 或 `未发现明显重复`，并展示搜索者摘要。
- 候选按语义相似度倒序展示，最多 5 条；每条显示候选类型、时间、相似度、标题和可用的原文链接。
- 页面不自动轮询，也不提供接受、拒绝或直接发布动作。查重结果是编辑辅助信息，是否属于同一事件由编辑结合事件进展最终判断。

## 服务端契约

- 页面使用控制台与插件共用的本地操作者 Bearer session。
- 请求复用 `POST /plugin/news-gen/search`，发送 `source_type = x_post`、`platform = x` 和编辑粘贴的 `post_text`。
- 服务端继续执行精确重复、embedding 候选召回和必要的搜索者 AI 复核；浏览器不实现相似度计算，不复制 Prompt。
- 返回结果中的 `top_candidates` 是最多 5 条候选，包含 `target_type`、`target_id`、`title`、`published_at`、`source_url`、`similarity`。
- 该请求会沿用插件查重的轻量日志留痕，不写入正式 `tasks`，不改变主流水线状态。
