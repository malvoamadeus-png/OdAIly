## 留存与回退

首次生产启动将新增信息流查询 SQLite、巡检表及压缩证据写入 `/data/OdAIly/system-observability`，不搬动现有数据库。新表初始化幂等，投影不调用 AI、不发送内容。若需关闭，回退 API 代码版本或清除 `ODAILY_SYSTEM_OBSERVABILITY_DIR` 令其回到默认目录；保留新数据库和证据。停止观测不影响业务 worker、不重投已提交稿件。
