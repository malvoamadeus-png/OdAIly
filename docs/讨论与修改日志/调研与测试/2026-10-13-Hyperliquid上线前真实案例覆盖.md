# Hyperliquid 上线前真实案例覆盖

本轮仅用于上线前规则及文稿验收，历史重建不接入常规监测。生产公共数据查询及测试样本保存在 odaily-official 的独立 hl_news_test_cases，正常监测仍为 13 个地址、4 个既有候选；未启用调度或公开发布。本地仅代码和离线测试。

扫描 75 个真实地址，来源为官方多周期盈亏榜与已收集报道中的完整地址。额外对 3 个重点地址查询 90 天保留成交窗口（两地址达到六页预算、各约 1.2 万条；一地址 817 条且可用历史结束）。报道仅用于发现地址，触发事实通过公共成交和官方历史收益核对。

最终 77 条测试案例，11/13 方向有案例（84.6%）；其中新观察地址快速建仓为真实成交下明确虚拟启动监测的测试，其他方向为真实历史/已有观察证据。因此纯事实覆盖为 10/13，不能宣称实时生产已经发现过全部方向。9 篇代表预览共同覆盖全部 11 个方向，未调用正式查重、编写者2或外部发布接口。

一个事件可命中多个方向，方向数量不能相加作为事件总数。清算方向已有实际清算，并不表示历史接近清算已取得案例。

单资产胜率案例仅一轮完整 ETH 交易、胜率 100%；文稿固定尾部必须写交易轮数及样本日期，不能冒称长期高胜率。账户高盈利案例使用操作前官方 portfolio perpAllTime 收益样本 20,735,396.23 美元，样本时间早于操作，不是已实现盈利。浮盈变化/回吐案例按连续成交、可核对成本与实际成交价格重建，不是历史标记价快照，也不声称完整盘中峰值。虚拟启动测试不等于钱包创建时间或我们真实首次发现时间。

未取得单资产历史盈利达到 800 万美元后重要操作、巨亏后加仓达到 300 万美元的可核对真实案例，不降低规则、不补造数据。空方向保留，继续上线前调整时可再定向补查。

验证：相关全套 113 项测试通过；补充历史账户属性截止时间与非合约结算排除后新增测试文件共 10 项通过。前端构建通过，生产 API 服务正常，Vercel 新 bundle index-D50zwXnJ.js 已生效。
