# GitHub 替代 X 搜索工具调研

调研日期：2026-10-25

## 结论

如果 `twscrape` 在当前账号登录或搜索步骤不可用，下一项适合做小规模验证的开源候选是 [`twikit`](https://github.com/d60/twikit)：它的文档提供按查询词搜索推文的调用，并提供带 TOTP 密钥参数的登录接口。它仍然模拟 X 的非公开网页接口，不能视作官方 API 或稳定的免费服务；需要真实账号会话，搜索可能因 X 的登录挑战、限流或内部接口变化而失败。

另一个候选 [`twitter-api-client`](https://github.com/trevorhobenshield/twitter-api-client) 也声明有搜索能力，但同样依赖非公开接口，且其维护新鲜度和当前兼容性本次无法核实。它不比 `twikit` 更适合作为首测对象。

不存在可据此推荐的“免费且稳定、无需登录”的 GitHub X 全站搜索 API。`snscrape` 可作为免登录抓取的旧实现参考，但不应假定当前仍可用。需要稳定性时仍应比较官方 X API 的付费搜索；免费搜索引擎索引只适合人工补充发现。

## 关于 twikit 的验证建议

1. 先用一个本人仍能控制登录邮箱、密码和验证器的账号；不要用卖家可能仍控制找回渠道的账号。
2. 在本机安装和运行，凭据与会话文件只留在本机。TOTP 设置密钥等同于可持续生成验证码的凭据，不要粘贴到聊天或日志。
3. 搜索一个低风险、结果明确的关键词，核对是否返回推文 ID、正文、作者和时间；仅登录成功不算搜索成功。
4. 单次成功只能证明当时可用。不要用多个账号轮换规避限流，也不要把非公开接口采集接入生产。

## 风险与限制

- 两个 Python 客户端都是第三方对 X 网页端行为的封装；接口变更、风控挑战和速率限制都可能让它们突然失效。
- “开源免费”只表示代码可获取/自托管，不代表 X 授权访问，也不表示服务稳定或没有账号成本。
- X 服务条款对未经许可的抓取和绕过技术限制有明确约束。生产用途应使用获准的官方 API；实验也应控制频率并遵守账号与平台规则。
- 本次执行环境访问 `api.github.com` 和 `raw.githubusercontent.com` 多次超时，故未能独立核对 2026-10-25 当天的最新 commit、release 或 issue，也没有安装或运行候选库。下面链接指向项目第一方仓库及其 README/API 源码位置，状态和实际可用性必须在联网环境中复核。
