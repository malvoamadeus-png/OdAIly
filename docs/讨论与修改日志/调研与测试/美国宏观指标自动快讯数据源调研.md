# 美国宏观指标自动快讯数据源调研

> 更新日期：2026-11-16。范围仅限指定宏观指标；当前发布目标只包括官方 Actual 和 Previous，不接市场 Forecast，也不判断是否高于预期。本文是数据源调研，不代表已接入程序。

> 实测边界（2026-11-16）：工作区已在未传 API Key 的情况下成功 POST 调用 BLS API v2，CES0000000001、LNS14000000、CUUR0000SA0 三条序列均返回数据；BLS 新闻发布页在本环境仍返回 403。Census API 当前连接超时，具体零售 selector 未实测；DOL 新闻站请求被拒。BEA API 可访问，但公开文档中的 DEMO_USER_ID 返回无效 UserID。Finnhub 与 Trading Economics 字段/认证说明可从其官方文档核对；当前未提供相应 API Key，未实际查询七项事件样本。

## 核心结论

指定指标的 Actual 和 Previous 都有官方来源，具备程序化发布的技术基础。BLS API 的就业、失业率和 CPI 序列已实测成功；Census、DOL、BEA 和 Fed 也有官方 API、发布表或声明页面可供解析，但这些来源仍需在部署环境用当期数据完成端到端验证。

当前目标不包含 Forecast 或“高于/低于预期”，因此不需要接 Finnhub、Trading Economics 等商业共识源，也不需要为缺少预测值阻塞发布。排程使用各机构官方日历；触发时轮询该项官方数据源，在统计期、单位和必要字段匹配后立即生成并发布。只有源数据未到、解析不确定或数值校验失败时才暂停该条快讯。

## 当前发布字段

- 零售销售：美国 10 月 Advance Monthly Sales 季调名义销售额月率。
- 每周初请失业金：季调 Initial Claims 人数。
- 利率决议：FOMC 目标联邦基金利率区间及本次维持/上调/下调结果。
- PCE：Headline PCE Price Index 同比。
- 非农：季调总非农就业人数月变化，单位万人。
- 失业率：季调全国失业率。
- CPI：按既有稿件采用总 CPI 季调月率和核心 CPI 季调月率；如仍需未季调 CPI 同比，应作为单独字段加入。两种口径不可混写。

建议快讯只写“指标公布值 + 前值”，例如“美国 10 月季调后 CPI 月率为 0.4%，核心 CPI 月率为 0.3%”。前值采用本次官方发布中经修订的上期值，并另存上一条快讯曾发布的历史快照。

## 既有 CPI 快讯样例的口径

样例“美国 10 月季调后 CPI 月率录得 0.4%，……季调后核心 CPI 月率录得 0.3%”包含两个**季调环比**指标，不是未季调同比：

- `CPI 月率` 是 CPI-U 全项目指数的季调环比，包含食品和能源；BLS 序列为 [CUSR0000SA0](https://data.bls.gov/timeseries/CUSR0000SA0)。
- `核心 CPI 月率` 是 CPI-U 剔除食品和能源后的季调环比；BLS 序列为 [CUSR0000SA0L1E](https://data.bls.gov/timeseries/CUSR0000SA0L1E)。
- 两项可由匹配季调指数计算 `(本月指数 / 上月指数 - 1) × 100%`，也可直接读 BLS CPI 发布表的 seasonally adjusted one-month change；正式 Actual 以发布表为核对依据。
- “高于市场预期”需要外部共识值，BLS 不提供。预测源必须对应同一统计期、同一 CPI 定义和 SA MoM 口径；若沿用这类样例，Forecast 至少需要总 CPI MoM 与核心 CPI MoM 两项。

这与“未季调 CPI 年率和月率”不是同一套字段。若自动快讯要复刻上述样例，应配置“总 CPI 季调月率 + 核心 CPI 季调月率”；若还要 CPI 同比，则另加常见的 CPI-U NSA 同比。只有确实需要 NSA 环比时，才用未季调指数自行计算，并要求预测值也采用 NSA 口径。

## Previous 的统一定义

建议将 Previous 定义为“本次发布时，官方来源所列的上一统计期值，经本次报告修订后”。它不同于“上一次快讯保存的初值”。Census 零售销售、DOL Claims、BLS 非农都可能在新稿中修订前期值；要保留读者当时看到的旧数，须另存上次发布快照。FOMC Previous 是上次会议的目标区间。PCE、失业率、CPI Previous 用本次官方数据版本计算前期观察值，旧稿不得因后续修订而静默改写。

## 官方源与机器读取

### BLS：就业报告、失业率、CPI

- API 文档：[BLS Public Data API](https://www.bls.gov/developers/)、[API FAQ](https://www.bls.gov/developers/api_faqs.htm)、[Version 2.0](https://www.bls.gov/developers/api_signature_v2.htm)。
- 序列：[CES0000000001 总非农就业](https://data.bls.gov/timeseries/CES0000000001)、[LNS14000000 失业率](https://data.bls.gov/timeseries/LNS14000000)、[CUUR0000SA0 CPI-U 全项目 NSA](https://data.bls.gov/timeseries/CUUR0000SA0)。
- 发布和排程：[Employment Situation](https://www.bls.gov/news.release/empsit.nr0.htm)、[CPI](https://www.bls.gov/news.release/cpi.nr0.htm)、[BLS Release Schedule](https://www.bls.gov/schedule/news_release/)。
- CES0000000001 API 返回季调总非农就业水平，单位 thousands of employees；实际月变化以 Employment Situation 发布表直接给出的值为准，发布表月变化除以 10 转为万人。相邻月 API 水平差分只作核对，因为水平值舍入后再做差可能相差 1 千人。
- 工作区已实测 API v2 POST JSON 对三条序列成功返回；新闻发布网页仍受 403 限制。Key 对额度/历史能力的影响以当前 BLS 文档为准。页面访问限制不能外推成 API 故障；API 月度水平/指数不含市场 Forecast。

### Census：零售销售

- [Advance Monthly Sales 发布页](https://www.census.gov/retail/marts/www/timeseries.html)、[Economic Indicators Calendar](https://www.census.gov/economic-indicators/calendar-listview.html)、[Census API 指南](https://www.census.gov/data/developers/guidance/api-user-guide.html)、[EITS API 文档](https://api.census.gov/data/timeseries/eits.html)。
- EITS 数据集 marts 对应 Advance Monthly Retail Trade Survey。先读取 metadata/variables，再确认 seasonally_adj、category_code 和 data_type_code。当前环境无法读取响应，具体 selector 未证实。官方发布表核对当期 Actual 和 revised Previous。
- Census Advance 数字是快速估计，后续月度零售贸易数据会修订；预期与历史快讯比较时保持 Advance 口径一致。

### DOL ETA：每周初请

- 官方源：[ETA News Releases](https://www.dol.gov/newsroom/releases/eta)、[Weekly Claims Data](https://oui.doleta.gov/unemploy/claims.asp)。
- 以当周新闻稿季调 initial claims headline/table 为解析入口，历史数据页作回溯校验。官方入口未找到 BLS/BEA 风格通用 JSON 时序 API。页面 DOM、表格标题和人数/千人格式可能变化，需校验后再使用。

### BEA：PCE

- 官方源：[PCE Price Index](https://www.bea.gov/data/personal-consumption-expenditures-price-index)、[BEA API](https://apps.bea.gov/api/)、[API 注册](https://apps.bea.gov/api/signup/)、[API 用户指南](https://apps.bea.gov/api/_pdf/bea_web_service_api_user_guide.pdf)、[发布日程](https://www.bea.gov/news/schedule)。
- API 用注册 UserID 查询 NIPA 表 T20304 月度指数并计算同比。发布日程列出 Personal Income and Outlays 日期，常规时间为 8:30 美东；等待 API 中出现新 reference month 后再生成稿件。
- BEA 后续月度发布及年度/综合修订会改写历史序列。存当时 API 响应及计算输入。

### Federal Reserve：FOMC

- 官方材料：[FOMC Meeting Calendars, Statements, and Minutes](https://www.federalreserve.gov/monetarypolicy/fomccalendars.htm)、[Press Releases](https://www.federalreserve.gov/newsevents/pressreleases.htm)。
- 会议日历提前给出安排，会后列出 statement HTML/PDF、Implementation Note 和可能的 SEP；statement 是决议事实源。决议声明通常在会议日 2:00 PM 美东发布，新闻发布会通常 2:30 PM，具体以当次官方日历为准。
- 结构化核验：[FRED DFEDTARL](https://fred.stlouisfed.org/series/DFEDTARL)、[FRED DFEDTARU](https://fred.stlouisfed.org/series/DFEDTARU)；[FRED API observations 文档](https://fred.stlouisfed.org/docs/api/fred/series_observations.html)要求 API Key。日频上下限是交叉校验，不替代当次 statement。

## Forecast API 调研备忘（当前不使用）

以下内容仅记录此前调查到的商业日历 API；当前发布目标不依赖这些接口，不应作为上线前置条件。

### Finnhub

Finnhub [Economic Calendar API](https://finnhub.io/docs/api/economic-calendar) 的官方 schema 提供 actual、estimate、prev、time、unit，并标注 Premium Access Required；历史 events/surprises 接口需要 Enterprise。字段形状适合统一宏观日历，但当前没有 API Key，七项是否都有事件、名称映射、estimate 的调查口径、单位和公开再分发许可均未核实。接入前需逐项保存 JSON 样本，并确认公开展示 actual/estimate/prev 的商业权利。CPI MoM 必须确认估值是 SA 还是 NSA；不匹配时不应显示“高于/低于预期”。

### Trading Economics

其产品文档定义 Economic Calendar API 字段：

- Actual：最新公布值。
- Previous：前一次发布值，如适用则为修订后数值。
- Forecast：代表性经济学家的共识预测。
- TEForecast：Trading Economics 自己的预测，不要与调查共识字段混用。
- Date：事件时间（UTC）；DateSpan 标记时间已确定或仍为估算；LastUpdate 是最近更新时间。

来源：[Calendar API by Country](https://docs.tradingeconomics.com/economic_calendar/country/)、[响应字段 Schema](https://docs.tradingeconomics.com/economic_calendar/schema/)、[iCalendar 导出](https://docs.tradingeconomics.com/economic_calendar/icalendar/)、[API 许可和分发说明](https://tradingeconomics.com/analytics/api.aspx)。

美国事件路径示例为 calendar/country/united%20states，认证参数 c=API_KEY，JSON 参数 f=json。iCalendar API 可按 country + indicator 拉取未来 1–12 个月事件。订阅按功能、请求量和数据分发范围定价；公开快讯须确认公开再分发权及 Forecast 字段授权。自动生产使用合同允许的 API，不用网页抓取代替 API。

**接入前仍需验证：**本环境没有 API Key，未实际检查七项在 Trading Economics 的事件名/indicator slug、event id、Forecast 单位、CPI 月率 seasonality、claims 单位或 FOMC Forecast 表达。逐项映射并保存 JSON 样本；Forecast 为空、口径不符或事件未匹配时暂停发布。发布前保存 Forecast 快照，因为 Actual 发布后 Forecast 或 LastUpdate 可能变化。

### FOMC Forecast 不等于 FedWatch

日历供应商的 estimate/forecast 若提供目标利率数值，应标作调查或供应商一致预期，并核实它表示目标区间还是单一利率。它不是 Fed 对当次决议的预测。CME [FedWatch Tool](https://www.cmegroup.com/markets/interest-rates/cme-fedwatch-tool.html) 展示基于联邦基金期货价格推算的各目标区间概率分布；这是市场定价概率，不是单点共识，也不是官方决议。若产品需要概率，应单独呈现分布及采集时点，不能压成一个“预期利率”。

## 排程和触发

没有覆盖 Census、DOL、BEA、BLS 与 Fed 的官方统一 API/webhook。排程按机构取得：

- CPI、就业报告：BLS Release Schedule 对应条目。
- 零售销售：Census Economic Indicators Calendar 的 Advance Monthly Sales 条目。
- 初请：DOL ETA 当周安排；常规周四 8:30 AM 美东，节假日会调整。
- PCE：BEA News Schedule 的 Personal Income and Outlays 条目。
- FOMC：Fed Meeting Calendar 及会后 statement。

按官方日历提前登记预期发布时间，到时轮询对应官方源，直到统计期/会议匹配且实际值齐全。不能仅因定时点已到就用缓存或空值发稿。保存计划时间、官方实际发布时间、抓取时间、来源 URL、原始响应、统计期、单位和快照版本；按美东时区处理夏令时。

## 自动发布阻断条件

1. Retail Sales 未确认 Advance/MRTS、季调及名义金额口径，或 reference month 错位时暂停。
2. Claims 未确认季调初请或未取得本次修订后的 Previous 时暂停。
3. FOMC 未从 statement 确认目标区间上下限，或误取 effective rate 时暂停。
4. PCE/CPI 缺少单位、频率、季调标志或比较期时不计算同比/环比。
5. NFP 当前月或前月 CES 水平/修订缺失时不计算万人变化。
6. 数值不一致、解析结构变化、单位异常或 API 延迟时转人工核验，避免错误宏观数据误导交易决策。
