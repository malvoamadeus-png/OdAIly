# X 推文投资线索挖掘：初步讨论

日期：2026-10-29。本文是基于生产样本的设计讨论，没有修改生产流程、Prompt、账号订阅或服务。

> 后续讨论已收窄范围：用户明确要求不核查原帖陈述、驱动逻辑、价值捕获或价格反映程度；产出是“驱动逻辑＋标的”，标的可暂空。用户否定将 Variational 内部持仓占比单独视作驱动，也否定将特殊钢工艺关系单独当作变量。下文保留最初讨论过程，其中核查流程及这两个正例不再代表当前方案。按收窄标准重新取样的材料见《2026-10-29-X推文投资驱动材料-第二轮》。

## 目标

从大量已采集的公开推文中，找出值得人继续研究的投资问题。输出可以没有具体股票或代币，也可以暂时没有明确多空方向，但要指出具体证据、可能影响的经济关系，以及最值得查证的一环。

优化目标是人的注意力：在可控的处理费用和等待时间内，提高用户愿意继续研究的线索占比，同时发现没有明确交易词的间接线索。

这些例子要分别标记事实可信程度、推断跨度和信息新旧。推断直接不代表可信，间接也不代表没价值。

## 建议的思考顺序

### 第一层：找值得多想一步的事实或关系

对短批次输入做轻量语义阅读，寻找以下模式，允许没有交易标的：

- 业务数据突破原有认知：绝对规模、增速、排名、业务结构或用户行为变化。
- 需求、成本或供给受约束：缺货、交期、涨价、认证、法规、替代品以及扩产周期。
- 公司以实际投入表态：收购、订单、资本开支、招人及正式合作；区分计划、意向和已执行。
- 技术改变产业分工：一个环节变便宜或变快后，其他环节会获得需求、失去利润或成为瓶颈。
- 数条独立消息形成方向：不同公司的同类投入，或需求端与供应端信息相互呼应。
- 新的解释或反例：作者指出了已有数据中未被充分讨论的变化，或提出了可以被验证的机制。

保持一个开放类别，容纳上述模式之外、但能说明具体经济关系的内容。没有新事件的技术知识可以成为背景材料，等待新变化触发关联。

### 第二层：沿经济关系延伸，并主动寻找断点

每个候选最多先延伸一到两步：

> 原帖主张 → 可能改变的经济变量 → 受影响的业务或资产 → 最关键的未证实条件。

对每条推断至少问一次：有没有相反机制？业务改善能否传给股东或代币？规模足以影响整体利润吗？市场是否已经交易了这个信息？

“AI 提高研发效率”既可能增加实验需求，也可能减少某些实验；“收入增长”可能来自短期补贴或不可持续活动；“模型公司进入某行业”可能让部分现有平台失去竞争优势。这些分支应由缺失证据决定，不能机械生成利好。

### 第三层：决定是否值得打扰用户

同时看潜在影响、具体证据、新颖程度、核查成本和与用户研究范围的关系，不让单一的模型置信分数决定。

事实可靠但没有增量的内容可以归档；事实未明但可迅速核查、影响很大的内容可以作为“待核查线索”进入研究队列；缺乏具体机制的宏大联想不推送。

## 节约费用与延迟的处理方案

1. **采集后并行分流。** 在快讯判断之前读取原帖和必要上下文，保持自己的消费进度。先复用已有抓取，不对每条推文重新访问 X。
2. **低成本整理。** 精确去重、识别转述来源、保留原帖时间、拆分作者正文与引用。明显空白或无信息内容可跳过；短回复、纯链接和图片帖若缺上下文，标为材料不足，必要时限额补充。交易关键词用于排序，不作为全部内容的硬门槛。
3. **轻量模型批读。** 每批最多约 20 条，或等待约 30–60 秒即处理；每条保留 ID 和来源边界。返回少量候选及一两句经济关系，允许零候选。长帖先保存数字、主体和关键关系，避免只按字符截断。
4. **保存简短的事件和关系记忆。** 把“两家公司分别进入同一领域”组合起来；把特殊钢等供应关系留作背景。保存来源和时间，限制每个候选的关联数量。同一原始报道被多人转发只算一个事实来源。
5. **仅对入围候选做较深推理。** 检查传导条件、反面机制、业务暴露及已有市场反应。对间接候选保留小份额的探索容量，避免所有资源都被显眼的行情帖占用。
6. **搜索最有价值的一处缺口。** 默认每候选至多 1–2 次浅搜索，按缺口查官方公告、原始报告、供应商或制度依据。没有找到关键证据就保留未知；用户选择继续研究后再深入。图片、链接正文、后续帖子也在此阶段按需读取。
7. **控制展示量。** 可先试每日最多 5–10 条，作为用户注意力预算而非必须完成的配额。明确而紧迫的事件可实时提醒，间接研究题可合并成低频列表。同一主题只有新增证据改变判断时才再次提醒。

费用主要来自全部候选文本的首轮阅读，以及少数入围项的搜索和推理。批处理减少请求数和重复指令，不能按批大小等比例减少正文 token。

以每日 1.2 万条、每条平均 250 输入 token 为纯示例，首轮正文约 300 万输入 token；尚未包含上下文、指令和输出，也尚未扣除去重。平均长度、压缩损失、不同模型的判断能力、服务限流和价格都需要实际测量，因此本次不给出人民币费用或固定延迟承诺。

## 最小输出格式

一张线索卡只需要：

- **发生了什么/原帖提出什么：** 只陈述来源支持的内容，明确待核查主张。
- **为什么值得想：** 一句具体的收入、成本、供需或竞争机制。
- **可能影响哪里：** 先写行业、业务环节；只有身份和关系明确时才列具体标的。
- **最该先查什么：** 一个能大幅提高或推翻判断的具体问题。
- **来源和时间：** 原帖、原始报道及首次被系统观察的时间；新事实、新推理或旧背景分别标明。

例：

> **传统资产可能正在成为 Variational 的主要使用场景之一。**
>
> 平台账号称，上线不到半年，传统资产市场已占约 43% 持仓量。若总持仓量同步上升，这可能显示新需求，而不仅是原有业务占比下降。
>
> **先查：** 总持仓量及手续费是否增长，增长是否依赖激励。尚未确认任何代币能分享这部分经济利益。

## 可用于后续离线试验的首轮指令草案

以下仅用于讨论，未安装到生产 Prompt：

> 阅读这批公开推文，找出值得人进一步研究的投资线索。允许没有 ticker、没有买卖词、没有明确方向，也允许整批没有候选。
>
> 寻找改变收入、成本、供需、竞争地位或资本流向的信息；保留具体的产业依赖关系和可验证的新解释。优先识别异常数据、瓶颈、真实投入、替代关系及多条独立消息的共同方向，同时允许其他有具体经济机制的模式。
>
> 对每个候选，只输出原帖 ID、原帖明确支持的主张、可能的经济机制、推断中最关键的缺口，以及它属于新事件、新解释还是背景知识。区分作者正文和引用，不能将引用主张自动归给转帖者；不能把重复转述当作独立证实。缺少图片、链接正文或上下文时写明缺失。
>
> 不要求为每个候选列投资标的。不要扩展成泛行业受益名单，不把营收、持仓量、交易量混为一谈，不把发生的股价变化当作未来方向，不将未核查的违法指控写成事实。

## 下一步怎样检验方向

建议先做离线、可人工复核的小规模试验：

1. 从完整采集输入中随机抽取约 500–1,000 条，另加用户提供的四类正例和明确的广告、行情感叹、旧闻、伪相关反例。正例集与随机样本分开报告，避免制造过高命中率。
2. 人工标注“愿意继续研究/保存背景/忽略”及理由，再比较一轮宽松阅读、仅关键词门槛和分层处理的差异。四个例子是必要覆盖项，不能作为唯一考核集。
3. 检查漏掉的间接线索。人工抽看模型淘汰样本，并单独检查非中文、无 ticker、图片、链接及短回复；否则只看入围结果会低估遗漏。
4. 第一轮看每十条候选中用户愿意研究几条、漏掉哪些思路、每天阅读分钟数、重复率、旧闻误报、实际 token/搜索开销和端到端延迟。收益表现需要另行设计验证。
5. 时间回放只允许使用当时实际可获得的帖子、上下文、搜索资料和资产关系，使用采集时间衡量系统当时是否已知，使用原帖时间衡量消息年龄；不得用后来的完整故事解释早期线索。

本次结论：输入已经有足够多样的材料支持小规模试验。最值得先验证的是“轻量广读产生少量研究问题，再对其中关键缺口投入搜索”的路线。间接线索的覆盖率、用户认可程度和费用仍待实际试验。
