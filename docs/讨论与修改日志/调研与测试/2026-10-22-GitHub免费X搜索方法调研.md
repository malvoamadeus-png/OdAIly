# GitHub 免费 X 推文搜索方法调研

调研日期：2026-10-22

## 结论

GitHub 上有免费的开源项目可以搜索 X 推文，但主流方案是模拟 X 网页端的非公开接口，通常需要一个或多个真实 X 账号的登录会话。它们的软件免费，不代表能匿名、稳定或符合 X 服务条款地抓取。根据 X 当前条款，未经 X 书面许可抓取服务内容被明确禁止，因此不建议将这类方法用于 OdAIly 的生产采集。

若要求官方且可持续，X API 的 Recent Search 提供最近 7 天搜索，但当前文档采用按用量计费，公开价格为每条 Post 读取 $0.005；搜索能力本身并非免费配额。新用户可获得有条件、需先购买或启用自动充值的促销额度，不能视为长期免费层。

## GitHub 项目

### twscrape：当前最值得验证的开源候选

- 仓库：[vladkens/twscrape](https://github.com/vladkens/twscrape)
- GitHub 仓库简介称其为 Python 库和 CLI，支持 X/Twitter 抓取、多账号轮换和速率限制处理；README/实现应作为使用前确认账号会话要求、搜索接口和近期兼容性的依据。
- 项目许可为 MIT，意味着软件可免费使用，不意味着 X 数据访问获得授权，也不免除 X 的条款约束。
- 实际成本包括账号维护、可能的代理或运行环境，以及接口失效后的维护；登录挑战、账号锁定、速率限制和 X 内部接口变动都可能导致搜索中断。
- 本次没有把它当作匿名公开 API 进行运行验证。它不是 FxTwitter 的官方搜索接口，也不能据 GitHub 项目存在推断搜索长期可用。

### snscrape：旧式免登录抓取，需先验证兼容性

- 仓库：[JustAnotherArchivist/snscrape](https://github.com/JustAnotherArchivist/snscrape)
- README 曾列出 Twitter 用户、话题标签、关键词搜索等抓取器，项目可免费安装和自托管。
- README 列出 Twitter 用户、话题标签、关键词搜索等抓取器，但这只能说明项目设计支持这些功能，不能证明它在当前 X 网页端仍能成功搜索。此类实现依赖 X 网页端行为，X 改版后可能失效或需要补丁；接入前应核实近期提交、开放问题和实际请求结果。
- 项目采用 GPL-3.0。若要集成或分发，另需评估 GPL 义务；即使技术上能运行，也仍受 X 条款限制。

### 搜索引擎索引：可人工辅助，不能替代实时搜索

Google、Bing 等搜索引擎有时收录公开的 `x.com` 页面，可通过 `site:x.com`、关键词和日期筛选做人工发现。但它们受爬取、索引与缓存影响，覆盖不完整、更新延迟且搜索语法不等于 X 原生查询。没有由 X 保障的完整性、稳定 API 或可依赖的结构化字段；不适合作为自动化热点监控的主数据源。

## 官方 X API 对照

- [Search Posts 文档](https://docs.x.com/x-api/posts/search/introduction)：Recent Search 查最近 7 天，文档称对开发者可用；需要获批开发者账号、Project/App 和 API 凭据。每页最多 100 条，可分页。
- [定价文档](https://docs.x.com/x-api/getting-started/pricing)：当前按实际读取资源扣除预购 credits，Post Read 为每条 $0.005；Pay-per-usage 计划每月最多读取 300 万条 Post。价格会变动，应以 Developer Console 为准。
- [免费 credit 激励](https://docs.x.com/x-api/getting-started/free-credits)：文档列出符合资格的新付费账号首次购入 credits 后返 $20，以及首次自动充值最高返 $50；返还规则有账号、卡片和付款资格限制，额度 3 个月过期，且文档注明功能逐步开放。这不是零付款的免费 API 层。
- Full-Archive Search 搜索完整历史档案，文档列为 Pay-per-use 与 Enterprise 可用，不属于免费搜索。

## 条款与工程判断

X [Terms of Service](https://x.com/en/tos) 明确说明，未经 X 事先书面许可，禁止以任何目的抓取服务；也禁止绕过技术限制或通过非公布接口访问/搜索服务。`twscrape`、`snscrape` 这类项目通过网页端或非公开接口工作，因此“开源免费”不能等同于已获 X 授权。

建议按用途选择：

1. 生产采集、需要归因可靠性与持续运行：使用官方 Search Recent，先设支出上限并核算每条读取成本。
2. 一次性人工查找：优先使用 X 网页搜索或搜索引擎索引；注意结果可能不完整和延迟。
3. 离线实验：可在隔离环境评估 `twscrape` 的搜索质量与账号风险；不要把它承诺为稳定服务，也不要将账号凭据或 cookies 交给第三方托管服务。
4. `snscrape` 可作为旧式抓取实现参考；不要仅凭 README 功能列表把它作为当前可用的生产依赖。
