## 入库标准

核心条目必须能写成“未来可观察的条件组合 → 可能方向”，而非对已发生新闻作否定或辩护。正向条件可以指向看跌：例如融资成本上升、收入兑现转弱、再融资依赖增加，共同出现时重资产业务风险上升。

适用范围与可搜索性分开标记：

- **范围 G3**：跨市场可复用；**G2**：适用于一类商业模式或产业；**G1**：限 Crypto 等单一领域；**G0**：绑定单个人物、公司或一次事件，只保留案例。
- **可搜索性 S3**：触发变量、方向和比较对象清楚；**S2**：变量可观察，但时间窗、阈值或确认条件尚缺；**S1**：主要是定性判断，难以稳定判断是否命中；**S0**：不是前瞻信号，不进入逻辑库。

这些等级评价的是复用与观察条件，不代表逻辑已通过回测。文章总结的观点也不等于受访者录音逐字原话。

## 领域候选

- **Crypto 现货与杠杆流**（G1 / S2）：上涨若伴随持续现货净买入，行情延续性通常强于仅由合约 OI、资金费率推升的行情；若 OI/资金费率上升而现货流量没有确认，行情更易受去杠杆冲击。[Owen 访谈](https://api.fxtwitter.com/2/status/2079024315505516686)。需要固定现货流口径、观察期和 OI/资金费率分位数。
- **Crypto 代币价值捕获**（G1 / S2）：若生态外付费用户和真实费用增长，且收入通过明确机制回流代币/质押者，产品增长才可能转成代币需求；若费用来自补贴或内部循环、代币持续稀释，用户增长不能直接外推成币价支撑。[Leslie 访谈](https://api.fxtwitter.com/2/status/2107623825680793791)。
- **山寨币流动性环境**（G1 / S2）：当 BTC 之外的资金流动性扩大时，长尾资产才有更强的整体承接；资金集中在 BTC 或退出 Crypto 时，山寨币缺少独立于 BTC 的流动性支撑。[Chris Lee](https://api.fxtwitter.com/2/status/2060225444700668261)。与同窗口相对强弱合用，不能单凭牛市叙事入场。
- **BTC 链上周期指标**（G1 / S1）：短期持有者成本线、PSIP、AVIV 等被访谈用作周期观察，但指标口径、权重和确认周期未统一，先保留研究候选，不作为已验证信号。[贝格先生](https://api.fxtwitter.com/2/status/2092607095447408704)。
- **Sell Put 资金流**（G1 / S1）：受访者将持续 Sell Put 视为潜在承接，但若无法从组合交易中区分开仓、平仓和对冲，方向可能被误读；暂不升为核心规则。[Frank Trading](https://api.fxtwitter.com/2/status/2083093674704208084)。
- **生态网络效应**（G1 / S2）：同一批用户和做市资金争夺流动性时，交易深度和真实留存更强的平台可能吸走竞争者的成交与费用；只上新交易对或短期补贴不足以证明护城河。[Mable Jiang](https://api.fxtwitter.com/2/status/2078366735133208688)、[Alu](https://api.fxtwitter.com/2/status/2105530726041186488)。
