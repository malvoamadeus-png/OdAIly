# 市场情绪任务书

## 目标

从 X Agent 已有账号中提取大市值 Crypto 和美股相关发言，形成“标的 + 情绪”的内部观察结果，不发布快讯。

## 账号初始筛选

系统直接检查已有账号最近约 30 天的代表性内容，批量提出并写入初始订阅开关。优先纳入持续讨论主流 CEX 可交易 Crypto 标的、主要美股、指数和 ETF 的二级交易者。无法确认或样本不足的账号保持仅热点话题开关。

首版不依赖精确市值接口。中心化交易所可交易性是大市值的主要代理；链上低流动性代币、新发射代币和 degen 语境默认不纳入市场情绪。一个账号可以同时打开市场情绪和项目推介。管理员只在网页上修正开关。

### 任务 1：找出真正的二级交易者

1. 从 X Agent 已有账号中读取最近约 30 天内容，不从其他信源补充账号。
2. 对每个账号抽取代表性样本：明确谈论 BTC/ETH/主流 CEX 标的、美股、指数、ETF、宏观交易或仓位观点的内容。
3. 判断账号是否持续讨论可在主流中心化交易所交易的标的，而不是只根据单条热门帖子判断。
4. 排除主要内容是链上新币、低流动性 Meme、发射盘、喊单链接或几万/几十万美元小市值项目的账号。
5. 样本不足、主体不清或 CEX/链上属性无法判断时，不打开市场情绪，只保留热点话题默认开关。
6. 输出初始化表：账号、建议开关、代表性帖子、判断理由、排除信号和不确定性。
7. 批量写入初始开关后，管理员只在网页调整开关；系统不保存账号画像，也不重新计算覆盖人工调整。

### 任务 2：把内容变成“标的 + 态度”

1. 先从帖子中识别标的标准名、ticker、交易所符号或明确的大盘范围。
2. 标的归入 `大盘`、`Crypto具体标的`、`美股具体标的` 三种范围；无法确认的标的进入待确认。
3. 提取发言对标的的态度和依据，区分明确观点、条件观点、转述他人观点和纯行情描述。
4. 使用五级情绪：`极度狂热`、`偏多/乐观`、`中性/分歧`、`偏空/谨慎`、`极度恐慌`，另设 `证据不足`。
5. 同一帖子可关联大盘和具体标的，但不能把价格涨跌本身自动改写成狂热或恐慌。
6. 保存原帖链接、发布时间、账号、结构化标的、态度、简短依据、模型和处理状态。
7. Luna 失败时调用 Terra；两者都失败或输出不合规时进入失败队列。

### 任务 3：呈现和管理追踪账号

1. X Agent 账号一览表展示 handle、显示名、三个订阅开关、最近采集、最近分析和最近错误。
2. 提供按“已打开市场情绪/未打开”筛选和批量操作，但批量操作仍只写短事务。
3. 账号目录不保存账号画像或开关变更记录；初始化判断依据留在本地筛选报告，运行时结果页只展示实际来源帖子。
4. 情绪结果页从标的进入来源列表，显示贡献账号、原帖时间和链接；来源加载使用分页，不一次加载全部帖子。

### 任务 4：共享采集与性能

1. 市场情绪不建立独立抓取线程；使用 X Agent 共享采集结果。
2. 账号开关变更立即持久化，worker 在固定配置窗口批量重载；不在请求内等待抓取或模型。
3. 同一账号连续点击只保留最终状态；同一帖子以稳定来源 ID 去重。
4. 分析任务使用有界队列和并发上限，模型调用失败可重试但不阻塞账号配置。
5. 市场情绪汇总按 1 小时、24 小时、7 天窗口计算，默认展示 24 小时快照。

### 额外任务与验收

- 首版不建立额外的标的配置表；管理员只通过账号订阅开关纠正分类，后续再根据实际误报决定是否增加独立的标的规则。
- 对 BTC/ETH、大盘、美股指数、明确情绪、纯价格转发、链上小币和混合观点做历史回放。
- 验收误把 Meme 账号纳入、漏掉真正二级交易者、标的识别错误、情绪级别漂移和重复计数。
- 本模块任何结果不得写入普通快讯发布队列。

## 内容处理

每条有效发言提取一个或多个标的、范围（大盘/具体 Crypto/美股）和五级情绪：极度狂热、偏多/乐观、中性/分歧、偏空/谨慎、极度恐慌；证据不足单独标记且不进入汇总。保留原帖链接、账号和时间。

按 1 小时和 24 小时窗口生成标的快照，默认页面展示 24 小时；可显示情绪变化、参与账号数和代表性来源。系统不把短期价格变化直接等同于情绪，缺乏明确态度的内容不强行分类。

## 失败与验收

JSON 不合规、标的无法确认或模型失败进入可见失败记录，不生成确定情绪。重复运行必须幂等；同一帖子不得重复计入。验收覆盖 BTC/ETH 等主流标的、美股指数、明确狂热与恐慌、纯行情转发、链上小币和混合观点。
